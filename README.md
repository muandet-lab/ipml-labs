# Imprecise Probability Labs

Static apps for GitHub Pages. No dependencies or build step.

1. Create a public GitHub repository, e.g. ipml-labs.
2. Extract this ZIP. Upload its contents (not the ZIP itself) to the repository root. Keep each app folder intact.
3. In Settings > Pages, select Deploy from a branch, branch main, folder / (root), and Save.
4. Open the URL displayed by GitHub Pages once deployment finishes.

App paths: probability-intervals/, desirable-gambles/, lower-prevision/.

All computations run in the browser. The apps have no ChatGPT login gate when hosted here.
